This is a mini-project where I built a real-time Gesture Controlled Volume System using Python, OpenCV, MediaPipe, and Pycaw. 
The application uses a webcam to detect hand landmarks and measures the distance between the thumb and index finger. 
That distance is mapped to the system volume level using Pycaw, allowing smooth control of volume through hand gestures without touching any hardware. OpenCV is used for video capture and drawing, MediaPipe for detecting hand landmarks, and Pycaw for adjusting system audio. 
Pinching fingers together decreases the volume, while spreading them apart increases it. The project demonstrates the power of AI and Computer Vision in enabling natural and intuitive Human-Computer Interaction. 
This is part of my learning journey in building innovative AI-powered tools using Python.
