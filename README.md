This is a mini-project where I developed an AI-powered real-time Gesture Controlled Volume and Brightness System using Python, OpenCV, MediaPipe, Pycaw, and Screen Brightness Control. The application uses a webcam to detect hand landmarks and measures the distance between the thumb and index finger to control system volume and screen brightness without physical contact. OpenCV is used for video processing and drawing hand landmarks, MediaPipe for accurate hand tracking, Pycaw for controlling system audio, and Screen Brightness Control for adjusting display brightness. The right hand is used for volume control, while the left hand controls screen brightness through simple gestures. This project demonstrates the power of AI, Computer Vision, and Human-Computer Interaction in creating smart touchless systems and is part of my learning journey in building innovative AI-powered applications using Python.
